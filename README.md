# ordenacao-supermercado
Projeto em C para ordenar preços de produtos usando Bubble Sort e Quick Sort.
# Sistema de Ordenação de Preços de Supermercado

## Objetivo

Desenvolver uma aplicação na linguagem C para organizar os preços de produtos de supermercado, utilizando os algoritmos Bubble Sort e Quick Sort.

## Situação-problema

Em um supermercado, organizar produtos de acordo com seus preços pode facilitar a comparação de valores e ajudar os consumidores a identificar os produtos mais baratos. Para resolver esse problema, o sistema utiliza dois algoritmos de ordenação para organizar os mesmos dez produtos em ordem crescente de preço.

## Funcionamento dos algoritmos

**Bubble Sort:** compara os preços de produtos vizinhos e troca suas posições quando estão fora de ordem. Esse processo se repete até que todos os produtos estejam organizados.

**Quick Sort:** escolhe um preço como pivô e divide os produtos em grupos menores e maiores que esse valor. Em seguida, aplica o mesmo procedimento recursivamente até ordenar todos os produtos.

## Conclusão

A aplicação demonstra como dois algoritmos diferentes podem resolver o mesmo problema de ordenação. Embora ambos produzam o mesmo resultado, o Bubble Sort geralmente realiza mais operações em conjuntos grandes, enquanto o Quick Sort costuma apresentar melhor desempenho médio para conjuntos maiores de dados.
